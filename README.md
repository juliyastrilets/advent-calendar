# Новогодний адвент-календарь

Интерактивный адвент-календарь по мотивам Genshin Impact. Дизайн и сценарий описаны в проектной спецификации.

## Запуск

Требуется Node.js `20.19+` или `22.12+` и npm.

```bash
npm install
npm run dev
```

Команды `npm run build`, `npm run lint` и `npm run preview` проверяют, собирают и запускают production-версию проекта.

## Документация

- [`docs/`](docs/) — документация и ТЗ: [дизайн-спецификация экранов](docs/DESIGN-SPEC.md), концепт-макеты, карты интерактивных зон и [манифест ассетов](docs/asset-manifest.csv).
- [`AGENTS.md`](AGENTS.md) и [`rules/`](rules/) — инструкции для ИИ по архитектуре, компонентам, стилям, именованию, качеству и тестированию.
